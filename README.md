# Wok & Spoon

A responsive recipe website featuring 20 popular Asian recipes and 10 dedicated Thai favourites. Every recipe has exact quantities, numbered beginner-friendly steps, and a practical mistake-prevention tip.

## Run locally

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000` in a browser.

## Verify

```powershell
pytest
ruff check .
```

The food images are AI-generated photorealistic assets created specifically for this project.
